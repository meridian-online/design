# meridian-egui inventory

Every public function, struct, enum, trait and static of this crate has a row here, and `tests/inventory.rs` fails when the crate and this file disagree in either direction (ADR 0011). A component's own config and response types share its row. Every `pub const` (the icon glyphs and `icons::ALL`, `GRID`, `STROKE_WIDTH`, `PROMPT_GLYPH`, `DEFAULT_TOAST_SECONDS`) is data and has no row of its own; the `Icon` row covers the glyphs. A public type alias or union would need a row like any other item; there are none today. The test reads source text line by line, so it does not see an item made by a macro, a re-export reached through more than one module, or a `pub use crate::` path outside `lib.rs`, and it fails rather than guess on a `pub mod` nested in an inline module.

- **component**: admitted through one of ADR 0011's two doors. `call sites` means at least three independent production call sites; a gallery call does not count, and a call that arrives only through another component of this crate is not independent. A shape the consumer builds by hand at three or more independent places counts as call sites for the component that replaces it, since each is a call waiting for it; `button` and `text_field` are admitted that way. Every other component is `requirement`: a named need of Brightfield that cannot be composed from the rest. The last column names the real callers.
- **composition**: composed from other rows, and says from what.
- **helper**: a public function or type that draws no component of its own.

The callers were searched in Brightfield at revision 7b6ddba1 (`crates/`, tests excluded). The components below predate the inventory and were admitted under ADR 0011.
